## 1. Overview

The **VoiceBack PWA** is an accessible, role-gated healthcare frontend built with React 19 and Vite. Designed specifically for aphasia patients, speech therapists, and caregivers, the application delivers:

1. **Patient Communication Hub:**
   - Physical microphone capture for patient speech attempts.
   - Integration with Wispr Flow / backend speech normalization.
   - Ephemeral dynamic response choice display generated by the Gemini Context Engine.
   - Explicit patient selection and confirmation.
   - Stored ElevenLabs voice synthesis playback.
2. **Web Bluetooth Audio & Telemetry Bridge:**
   - Connects directly to the ESP32 smart neckband (`VoiceBack-Neckband`) via Web Bluetooth GATT.
   - Decodes synthesized MP3 audio, resamples to 16kHz 16-bit Mono PCM, and streams 180-byte chunks to ESP32 for physical speaker playback.
   - Subscribes to 50Hz BioAmp EXG Pill analog telemetry for muscle calibration and effort monitoring.
3. **Clinical Role-Based Portals:**
   - **Patient Portal:** Single-setup persistent authentication, speech exercise modules, emergency SOS trigger, and dynamic conversation cards.
   - **Doctor Portal:** Clinical session tracking, patient progress analytics, and appointment management.
   - **Caregiver Portal:** Live patient monitoring, emergency alerts, and contextual communication prompts.

## 3. Web Bluetooth (BLE) Architecture (`deviceService.js`)

The PWA connects to the ESP32 neckband over Web Bluetooth:
- **Device Advertised Name:** `VoiceBack-Neckband`
- **Primary Service UUID:** `4fa8c001-1278-472e-b997-63992e716a4d`
- **BioAmp Telemetry Characteristic UUID:** `beb5483e-36e1-4688-b7f5-ea07361b26a8` (Notify)
  - Receives 50Hz JSON packets: `{"raw": 1842, "flt": 1835.45, "vlt": 1.479}`
- **Audio Output Characteristic UUID:** `cba1483e-36e1-4688-b7f5-ea07361b26b9` (Write Without Response)

### Audio Streaming Pipeline:
1. Receives ElevenLabs synthesized MP3 Blob from `/api/v1/voice-profiles/synthesize`.
2. Decodes MP3 into raw audio buffer via browser `AudioContext`.
3. Resamples to **16,000 Hz 16-bit Mono PCM** using `OfflineAudioContext`.
4. Slices PCM data into **180-byte chunks**.
5. Streams chunks sequentially to the ESP32 audio characteristic, which transfers them directly to the MAX98357A I2S DAC (`GPIO26`, `GPIO25`, `GPIO22`).

## 4. Voice Cloning & Fallback Guidelines

- **ElevenLabs Integration:** Patients enroll voice samples via `VoiceCloningModule.jsx`. The assigned `voiceId` is stored in MongoDB `VoiceProfile` and reused for all subsequent speech output without re-cloning.
- **Kannada PVC Policy:** ElevenLabs `eleven_v3` synthesizes Kannada text, but ElevenLabs PVC does not officially list Kannada as a supported training language. When patient cloning is unavailable or unverified for Kannada, the system uses an approved fallback voice rather than misrepresenting synthesized output as a personalized voice clone.
- **Offline Fallback:** If cloud synthesis is unreachable, `voiceService.js` falls back to browser native SpeechSynthesis with Chromium queue-unblocking handlers.

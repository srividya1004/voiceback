# Models Directory

This directory will contain Mongoose database models for:
- UserLogin (Authentication & User Roles)
- Patient (Clinical Profile)
- Doctor (Practitioner Information)
- Caregiver (Caregiver Relationships)
- VoiceProfile (TTS Speech Settings)
- EMGProfile (sEMG Calibration & Baselines)
- TherapyProgress (Session Scores & Tracking)
- CommunicationHistory (Speech Attempt Logs)
- Appointment (Clinical Scheduling)
